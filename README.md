# Punisher: Zombie Typocalypse

![Gameplay Screenshot](assets/screenshot.png) A fast-paced typing game where you play as the Punisher, mowing down hordes of zombies by correctly typing words. Built with Python and Pygame.

---

## About The Project

**Punisher: Zombie Typocalypse** is a 2D survival game that turns typing practice into a thrilling battle against the undead. As zombies shamble towards you, your only defense is your keyboard. Type the words floating above their heads to eliminate them and rack up your score. With increasing difficulty, multiple zombie types, and customizable settings, this game is a great way to test and improve your typing speed and accuracy.

### Built With

* [Python](https://www.python.org/)
* [Pygame](https://www.pygame.org/)

---

## Features

* **Action-Packed Typing Gameplay**: Defend your position by typing words to shoot zombies.
* **Dynamic Difficulty**: The speed and spawn rate of zombies increase as you play.
* **Multiple Zombie Types**: Face off against different zombies, from slow Shamblers to tough Brutes, each with varying word lengths.
* **High Score System**: Keep track of your personal best and challenge yourself to beat it.
* **Animated Player**: The Punisher character has idle and shooting animations.
* **Customizable Experience**: Change the game background from the in-game settings menu.
* **Sound Control**: Includes background music with an easy-to-use mute toggle.
